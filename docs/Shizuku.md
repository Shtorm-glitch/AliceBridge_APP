# AliceBridge: дополнительный режим Shizuku

Основной способ — **Root / DFRoot**. Shizuku выбирается вручную на главном экране. Если получение root через DFRoot завершилось ошибкой, приложение предлагает открыть инструкцию Shizuku. Без выбора пользователя другой режим не запускается.

Требования: Android 13+, работающий Shizuku и доступ к интернету. Режим экспериментальный: скрытые сетевые API могут отличаться у производителей. Root телефона и KernelSU для него не требуются. Наличие root на самой колонке по-прежнему зависит от модели и прошивки.

1. Установите [официальный Shizuku](https://github.com/RikkaApps/Shizuku/releases/latest).
2. Подключите телефон к Wi-Fi. Включите режим разработчика и **Беспроводную отладку**.
3. В Shizuku откройте **Запуск через беспроводную отладку → Сопряжение**.
4. В настройках беспроводной отладки выберите **Подключить устройство с помощью кода сопряжения**. Введите код в уведомлении Shizuku.
5. Вернитесь в Shizuku и нажмите **Запустить**. Статус должен показывать работающую службу.
6. В AliceBridge выберите **Shizuku · без root → Настроить Shizuku → Разрешить доступ AliceBridge**. Подтвердите запрос.
7. Отключите другой VPN и уже запущенный хотспот. Нажмите **Начать через Shizuku**.
8. Дождитесь готовности точки доступа: приложение проверяет, что хотспот использует созданную сеть и нужный DNS. Название и пароль появятся после успешного запуска.
9. Добавьте колонку в «Доме с Алисой» через эту точку доступа. Вернитесь в AliceBridge и наблюдайте за настройкой.
10. После завершения переключите колонку на домашнюю Wi-Fi сеть. В режиме Shizuku сохранённый пароль домашней сети автоматически не извлекается — введите его вручную.

После перезагрузки телефона Shizuku нужно запускать заново. Для этого режима перезагрузка ради удаления DFRoot не нужна. Если ранее использовался DFRoot, его напоминание о перезагрузке остаётся актуальным.

При потере Shizuku, сетевого движка или нужного маршрута настройка останавливается с ошибкой. Можно завершить сессию и выбрать основной режим Root. Ошибки доверия сертификату на колонке Shizuku не исправляет.

Диагностика: журнал → поделиться полным архивом. Для Shizuku добавлен `phone-shizuku-network.json`; экспорт не запрашивает root телефона.
