[b]Требования и принцип работы[/b]

Телефон ARM64 с Android 12L+. Основной вариант использует существующий root или встроенный DFRoot — эксплуатацию уязвимости ядра телефона для временного root через KernelSU. Совместимость зависит от ядра, одной версии Android недостаточно.

На колонке используется отдельный механизм: DNS направляет запросы настройки на сервер, который выдаёт конфигурацию для включения root ADB. При необходимости предлагается подготовленная прошивка для отката. DFRoot выполняется на телефоне, а не на колонке.

[b]Настройка через DFRoot[/b]

1. Установите AliceBridge, совместимый менеджер KernelSU и «Дом с Алисой».
2. В AliceBridge нажмите «Начать настройку», выберите менеджер и дождитесь проверки или получения root.
3. Откройте KernelSU → «Суперпользователи» и выдайте AliceBridge права суперпользователя. Вернитесь в приложение.
4. Дождитесь готовности хотспота. Имя сети и пароль будут на экране. DNS по умолчанию — 78.24.223.83.
5. Сбросьте колонку к заводским настройкам. Добавьте её в «Доме с Алисой», подключив к точке AliceBridge. Вернитесь в AliceBridge и следите за этапами.
6. Дождитесь подключения ADB и завершения этапов. При необходимости отдельно установите YSE, SSH или Zsh.
7. Переключите колонку на домашний Wi-Fi через приложение, подключите телефон к этой же сети и дождитесь повторного подключения.
8. После использования DFRoot обязательно перезагрузите телефон: временный root и изменения ядра сохраняются до перезагрузки.

Если колонка уже доступна по ADB, приложение открывает панель управления без повторной настройки.

[b]Shizuku — дополнительный экспериментальный вариант[/b]

Требуется Android 13+. Root телефона и KernelSU для этого режима не нужны.

1. Установите [url=https://github.com/RikkaApps/Shizuku/releases/latest]официальный Shizuku[/url].
2. Подключите телефон к Wi-Fi, включите режим разработчика и «Беспроводную отладку».
3. В Shizuku выберите запуск через беспроводную отладку и сопряжение. В настройках Android откройте подключение по коду и введите код в уведомлении Shizuku.
4. Вернитесь в Shizuku и запустите службу.
5. В AliceBridge выберите «Shizuku · без root», откройте инструкцию и разрешите доступ AliceBridge.
6. Отключите другой VPN и уже работающий хотспот. Нажмите «Начать через Shizuku» и дождитесь готовности точки.
7. Подключите колонку через «Дом с Алисой», затем вернитесь в AliceBridge.

После перезагрузки телефона Shizuku надо запускать заново. Пароль домашнего Wi-Fi в этом режиме вводится вручную. Готовность хотспота ещё не доказывает работу интернета на колонке; при ошибке отправьте диагностику.

[b]Первая Станция[/b]

Для yandexstation с платой tulip реализовано получение постоянного root через boot-root.img. До первого ADB настройка обычная. Далее приложение проверяет модель и исходный boot, сохраняет резервную копию на телефон, записывает подготовленный образ, сверяет SHA-256 раздела, перезагружает колонку и проверяет root ADB. Этот образ не используется для других моделей. Сброс настроек не восстанавливает заводской boot.

[b]Если не работает[/b]

Ошибка Bluetooth при настройке: полностью закройте «Дом с Алисой», откройте снова и повторите подключение.

«Нет интернета»: проверьте DNS 78.24.223.83 в настройках AliceBridge и отключите сторонний VPN на время проверки. Откройте журнал: тайм-ауты DNS, загрузка прошивки и отсутствие ADB — разные этапы проблемы.

Для разбора проблемы откройте журнал → «Поделиться диагностикой» и отправьте ZIP целиком. В нём сохраняются подробные события и состояние сети.
