# AliceBridge Agent

Отдельная служба на колонке для уже полученного root. Она **не получает root**, не
патчит boot и не запускает эксплойты; при старте требует существующий root.
Основное описание и матрица поведения: [docs/station-agent.md](docs/station-agent.md).

## Задачи

- восстановление домашней сети после загрузки без телефона, с откатом при ошибке;
- подтверждение смены Wi-Fi по ADB/SSID и только затем остановка временного хотспота;
- мониторинг и восстановление ADB/SSH;
- профильная защита OTA после каждой загрузки;
- обновление самого агента по подписанному манифесту.

## Файлы на колонке

| Путь | Назначение |
| --- | --- |
| `/data/quasar/alicebridge-agent/agent` | исполняемый файл службы |
| `.../config.json` | домашняя сеть и незавершённая транзакция, `0600` |
| `.../control.sock` | Unix-сокет `0600` в каталоге `0700`, без сетевого порта |
| `.../release.json` | исходный подписанный конверт обновления |
| `.../agent.previous` | откат при обновлении |
| `.../agent.log` | ограниченный журнал без учётных данных |

Автозапуск: `/etc/init.d/S99zzalicebridge-agent` или точная строка в `/etc/rc.local`
(Linux); для Станции 1 — `/system/etc/rc.local`. Чужие строки не изменяются.

## Обновление и подпись

Бинарники и `manifest.json` публикуются отдельно от APK. Транспорт — HTTP, поэтому
обязательна проверка **ECDSA P-256 / SHA-256** подписи манифеста, затем размера,
архитектуры и SHA-256 исполняемого файла. Публичный ключ вшит в APK и установщик.
Приватный ключ хранится офлайн (`private/agent-signing/private.pem`), не коммитится
и не попадает в APK. Без резервной копии ключа выпуск совместимых обновлений
невозможен.

## Сборка и выпуск

```sh
cd agent
go test -race ./...
python3 build_release.py --version 1.0.2 --build 3 \
  --key ../private/agent-signing/private.pem
```

Загрузить `agent-arm64`, `agent-arm`, затем атомарно заменить `manifest.json` на
`/agent/manifest.json`. Манифест публикуется последним; версионированный бинарник
после публикации не перезаписывается. Номер сборки агента не связан с версией APK.

## Поддерживаемые платформы и ограничения

- Linux ARM64/ARMv7 и Станция 1 (tulip).
- Макс и другие Android: работа до перезагрузки, без постоянного автозапуска; это не
  постоянный root.
- Служба не устанавливает SSH, не возвращает намеренно удалённый SSH и не отключает
  чужие защиты OTA.
- Обновление/удаление блокируются во время смены Wi-Fi.
- Проверки на реальных колонках должны фиксироваться отдельно; сборка и unit-тесты
  не заменяют холодный старт и смену сети на устройстве.
