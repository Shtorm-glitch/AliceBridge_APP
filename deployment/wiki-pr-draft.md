# Будущий PR: Root с Android через AliceBridge

Статус: опубликован PR #10, https://github.com/Marker284/yandex-station-extended/pull/10. Ревью RandomTNT запрошено комментарием; назначение через Reviewers недоступно аккаунту.
Репозиторий: Marker284/yandex-station-extended.
Ревьюер при отправке: RandomTNT.

Отдельная инструкция AliceBridge в разделе «Начало работы»: требования Android/ARM64/KernelSU, временный root DFRoot через DirtyFrag, DNS-механизм включения ADB колонки, порядок настройки и переход на домашний Wi-Fi. Добавлены ссылки из текущего руководства и меню. APK раздаётся с http://78.24.223.83/AliceBridge-0.4.7.apk; бинарники и исходники в PR не включать.

Полный проход проверен на Станции Лайт 1 с 0.369.1.46.4778262442.20261013.297 и Galaxy S25. Проверка Мини 1 указана по сведениям автора приложения. Для других устройств совместимость не заявлена.
